# CyberSentryAI

**AI-Powered Website Cybersecurity Monitoring Platform**

CyberSentryAI is a cybersecurity platform designed to help website owners and security teams identify potential vulnerabilities, analyze security risks, monitor threats, and receive actionable remediation guidance.

## Core Features

- Website security monitoring
- Vulnerability detection and analysis
- AI-assisted security assessments
- Risk identification and prioritization
- Security recommendations and remediation guidance
- Threat monitoring and reporting

## Technology Stack

- Next.js
- React
- TypeScript
- CSS
- Node.js

## Getting Started

### Prerequisites

- Node.js
- npm
- Git

### Installation

Clone the repository:

```bash
git clone https://github.com/Fouzia2510/cybersentry-ai.git
```

Navigate into the project:

```bash
cd cybersentry-ai
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.
